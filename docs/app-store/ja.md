## Description (4000)

メニューバーのアイコンが多すぎませんか。CleanMenuBarは見たくないアイコンを隠し、必要なときに表示します。

使い方

メニューバーに2つの項目が現れます。細い区切り「|」と矢印「>」です。

⌘を押しながら、隠したいアイコンを区切り「|」の左側へドラッグします。その右側にあるものは常に表示されたままです。矢印「>」をクリックすると折りたたみ、「<」で展開します。どこからでも⌃⌥⌘Cを押しても同じです。

並べ替えが終わったら、設定で「区切りを隠す」をオンにすると、画面には矢印だけが残ります。

位置は再起動後も保たれます。macOSが各アイコンの場所を記憶します。

機能

• クリック、グローバルショートカット、またはポインタを重ねるだけで隠す・表示する
• 常に非表示のセクション。決して見たくないアイコンのために
• 5、10、15、30、60秒後の自動折りたたみ
• 起動時に前回の状態を復元
• ログイン時に開く
• 9言語対応

権限は不要

CleanMenuBarは特別な権限を一切要求しません。アクセシビリティも画面収録も不要です。メニューバーのツールとしては異例ですが、グローバルショートカットがそれらを必要としないAPIを使い、アプリが画面を読まないため可能になっています。

ネットワーク権限もありません。コードが試みても何も送信できません。自身のサンドボックスコンテナの外は一切読みません。

macOS 27が必要です

macOS 27はメニューバーを単一のウインドウとして作り直し、一部のアプリが使っていた手法は動かなくなりました。CleanMenuBarはmacOS 27の一般公開の翌日に、その環境上で直接開発・実測されました。

それ以前のmacOSには対応していません。その必要もありません。そこでは従来の手法がまだ機能します。

macOS 27はIntel Macでは動作しないため、CleanMenuBarはApple Siliconを必要とします。
