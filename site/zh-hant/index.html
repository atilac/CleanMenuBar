为什么会有它

macOS 27 將選單列重建為單一視窗，並讓我一直使用的隱藏圖像 App「Hidden Bar」失效。它所依賴的技術不再奏效。

CleanMenuBar 衍生自 Hidden Bar，機制經過改寫，並在 macOS 27 Golden Gate 公開發布（2026 年 9 月 14 日）次日於該系統上直接開發與實測。

功能

  • 隱藏与顯示點一下、全局快速鍵，或仅将指针停留其上。
  • 始終隱藏區域即使展開也保持隱藏的第二段區域。
  • 自动收合5、10、15、30 或 60 秒後。
  • 无需權限无需輔助使用，无需螢幕錄製。執行于沙箱中。
  • 九种語言繁體中文、簡體中文、英文、葡萄牙文、西班牙文、法文、德文、日文、俄文。
  • 不收集任何資料无網路、无遙測、无帳號。

設定步骤

  1. 按住 ⌘，将想隱藏的圖像拖曳至 CleanMenuBar 分隔符號的左側。
  2. 位于分隔符號右側的圖像始終保持可見。
  3. 點一下箭頭收合或展開，或在任意位置按 ⌃⌥⌘C。
  4. 整理完成後，開啟隱藏分隔符號，螢幕上便只留下箭頭。

位置在重新啟動后依然保留——macOS 会記住每个圖像的位置。

安裝

下載 .dmg，将 CleanMenuBar 拖入「應用程式」，然后開啟。

该 App 使用 Developer ID 簽署并经 Apple 公證，因此開啟时不会出现警告。在上架 Mac App Store 之前，上方下載是官方取得方式。
